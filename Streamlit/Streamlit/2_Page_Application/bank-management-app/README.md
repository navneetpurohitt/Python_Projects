# Bank Management Application

This is a multi-page bank management application built using Streamlit. The application provides various features for managing customer accounts, viewing transaction history, accessing loan services, and obtaining customer support.

## Features

- **Account Management**: Create, update, and delete customer accounts. View account details.
- **Transaction History**: Fetch and display transaction history based on account number or date range.
- **Loan Services**: Apply for loans, check loan status, and calculate loan eligibility.
- **Customer Support**: Submit inquiries through a contact form and access a FAQ section.

## Installation

To run this application, you need to have Python installed on your machine. Follow these steps to set up the project:

1. Clone the repository:
   ```
   git clone <repository-url>
   cd bank-management-app
   ```

2. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

To start the application, run the following command in your terminal:
```
streamlit run app.py
```

Once the application is running, you can navigate through the different pages using the sidebar.
